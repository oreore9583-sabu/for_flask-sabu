# for_flask
## 自己紹介
  プログラミング歴1年ぐらいの趣味でやってる人です。
  見てもらったら分かる通り、ここではパーサーを作ってflaskで作りました。
## なぜ作ろうと思ったか
  やっぱり、pythonがわかりやすかったんで書くようになったのと、webを公開したいと思って、簡単そうなフレームワーク調べたらflaskがヒットしたんでflaskにしました
### なぜrustで書かれたものもあるのか
  言語のルーレット回したら偶然rustが出て、そのとき、パーサーを作るのを目標にしてたんで、rustでもパーサーを作りました。コメント機能(あったら(多分無い))でコメントしてってくれよな！
  あと、workersのURLはなるべく入らんでほしい。
